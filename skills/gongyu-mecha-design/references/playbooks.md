# 风格与模块方法

以下为源照片与真实分件的归纳，不是作者原话。证据S编号见source_inventory/evidence。

| 风格要素 | 样本依据 | 新设计如何运用 |
|---|---|---|
| 短厚块状主体、台阶装甲、边框与筋条 | S01/S02/S04/S05/S09成品照片 | 先大体块后局部层次，保留大平面与工具轴线 |
| 四/六轮、同心圈轮毂、规律胎纹 | S01/S02/S04/S05/S07/S09 | 轮组有明确承载位置，不加无职责小齿轮 |
| 壳体/结构/工具分色 | 上述照片与3MF槽 | 大色块兼具拆件职责；原槽色不等于唯一实物颜色 |
| 分段机械臂与替换工具端 | S01钻、S04叉、S05斗、S09链锯 | 用作业功能决定关节轴与伸展，不先堆装饰 |
| 多足为另一支结构 | S10照片及22实例 | 保留承力/运动链思路，不把轮车规则强套多足 |

## 代表样本怎么选

207重型钻车看六轮与宽连接/叉形臂；41叉车看紧凑底盘和立式工具；43挖掘机看两段臂与斗；86链锯车看长工具端；156看侧壁作业模块；夫诸看重复腿结构。43/46的A1mini与P1S文件是机型变体，不把它们作为独立视觉设计投票，避免重复文件夸大结论。

每个新作先写“用途、主要作业端、底盘型式、主体轮廓、活动自由度、颜色职责、免胶进入方向”。用3个主块表达，初稿确认后才做槽/格栅/筋条。目标是模块工程机甲语言，不能照搬作者名字/署名来代替原创设计过程。
