# Concepts

- [块状主体与装甲层次](001-块状主体与装甲层次.md) - 成品照片中的主体以短厚盒状体块为主，台阶、边框、浅槽、筋条构成局部层次；工程端伸出主体形成明确功能方向。新作先做底盘/车壳/工具三个体块，再加局部细节，不从装饰碎片堆造型。
- [轮毂与成组重复](002-轮毂与成组重复.md) - 四轮/六轮工程车在多个样本重复出现，同心圈轮毂和规则胎纹在源照片可见；S10为多足机甲例外。重复的轮子/腿是视觉节奏与制作效率来源，不把所有作品强制为六轮。
- [功能色块](003-功能色块.md) - 照片体现壳体、结构、作业端分区配色，多个实例显示多种实际配色，不存在唯一黄白黑配色。3MF槽色并不等于实物照片颜色。新作按结构职责选2—3个颜色区，避免在同一零件上零碎涂色增加逐层换色。
- [模块与变体](004-模块与变体.md) - 钻头、叉、挖斗、链锯为不同工具端，底/中/盖/臂/轮在源部件名中反复出现。可归纳底盘—连接/回转层—外壳—作业臂—工具分层方法；反复命名不证明跨型号几何或接口兼容。
- [接口事实与边界](005-接口事实与边界.md) - 207的收腰块、宽板、叉形分段臂是已观察实例；不同样本包括轴、孔、连接件。不得将用户提供的“卡扣”描述直接认定为同一种弹性锁扣。连接方式需要原网格剖面、配对尺寸与进入路径，照片不足以证明内部弹性机制或扣合寿命。
- [盘级覆盖](006-盘级覆盖.md) - S01—S09均明确有盘级by object覆盖，全局print_sequence却是by layer；S10单色22父对象无该盘级覆盖。对原文件看全局或数父对象都不能独自判断最终挤出顺序，必须检查实际G-code。
- [样本工艺](007-样本工艺.md) - 读取的10份源3MF项目值均为0.2mm、3墙、15%填充、support=0、prime_tower=1。这只是源设置，不等于全部重新切片与实物打印通过。用户要求无塔是目标适配要求，不能说源作者默认无塔。
- [尺寸与方向](008-尺寸与方向.md) - 原打印姿态包含局部和父组变换，应保留接口朝向；组宽高仅用于摆盘，不是装配后成品外形。STL没有单位/料槽/装配/打印设置，ZIP分件数不代表装配实例数。
