# Methods

- [原始网格学习路径](001-原始网格学习路径.md) - 查源哈希与署名→读取实例与变换→看成品与拆件→选择一个接口配对→剖面测量与路径检查→试打记录→生成新设计。不要看到相似结构就凭照片改成另一种关节。
- [独立新作设计路径](002-独立新作设计路径.md) - 功能一句话→一个主要作业端→底盘/主体/关节职责→三体块轮廓→分色与拆件表→局部装甲细节→本地Blender→小样→单盘按组切片。风格借鉴保留模块语言，新几何独立设计；直接源网格复用须注明复刻。
- [稳健免胶连接](003-稳健免胶连接.md) - 定位、承力、防脱分别设计；收腰块与槽、轴与轮孔整套测量，倒角/根部圆角与壁厚需结合喷嘴和方向。卡扣间隙用同材质同朝向梯度小样验证，不从某一模型推出统一毫米标准。用户曾实物反馈断轴/卡扣脆弱，不能用网格封闭覆盖失败。
