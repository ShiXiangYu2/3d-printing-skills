# 块状主体与装甲层次

成品照片中的主体以短厚盒状体块为主，台阶、边框、浅槽、筋条构成局部层次；工程端伸出主体形成明确功能方向。新作先做底盘/车壳/工具三个体块，再加局部细节，不从装饰碎片堆造型。
