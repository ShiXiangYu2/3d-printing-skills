# 接口事实与边界

207的收腰块、宽板、叉形分段臂是已观察实例；不同样本包括轴、孔、连接件。不得将用户提供的“卡扣”描述直接认定为同一种弹性锁扣。连接方式需要原网格剖面、配对尺寸与进入路径，照片不足以证明内部弹性机制或扣合寿命。
