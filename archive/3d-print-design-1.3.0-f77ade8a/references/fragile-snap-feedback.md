# 脆弱卡扣的实物反馈与改进

2026-10-06用户反馈钻臂工程车卡扣太脆弱，并提供底盘、机械臂和原参考红框照片。已实物打印不等于实物装配验证通过；此模型应记为physical_fit_verified=false，另记strength_feedback=failed，不继续推荐旧接口为可靠模板。

## 证据与未知项

v2脚本：固定销直径4.4mm、开槽2.8mm，穿过中心截面的两侧标称厚度各(4.4-2.8)/2=0.8mm，圆截面边缘更薄；轮轴开槽2.0mm中心余厚各1.2mm。C环外半径4.15mm、内半径2.75mm，径向壁厚1.4mm。以上是设计值，不是照片尺寸或材料测试结果。

照片可观察到薄分叉轴、孔周围悬垂/松散走线、支撑残留及较细的关节连接。用户已明确反馈脆弱，但照片本身不能确认每个断点和原因；不能把桥接面纹路直接归咎于欠挤出。耗材类型、断裂发生于去支撑/压入/活动、实际打印配置及尺寸仍待确认。

红框参考可见宽块状固定结构、较大的连接面、圆滑且较宽的关节过渡和有横向连接的骨架。只能借鉴可见承力路径，不能由照片推断内部倒扣、材料、间隙、强度和装入方式；没有尺标不能直接比较尺寸。

## 改设计前必须考虑

- 定位、承力、防脱分开：宽定位块/肩面承担剪切和扭矩，锁扣主要防脱。固定车身/底盖优先评估宽键、滑入导轨和独立保险结构，禁止机械地用两个细开槽销承担全部载荷。
- 卡扣不能只加厚：保留需要弯曲的有效长度与可释放空间，降低必要变形/倒扣量，增加承力宽度；较厚的短臂可能更难扣入。根部圆角缓解应力集中，厚薄渐变；不要让锐角槽端停在高弯矩根部。
- 关节环与连接梁应有宽根部和圆滑过渡，C口增加导入；若同耗材试件仍脆，改闭合轴孔+可更换打印销等免胶连接，接受必要的零件数增加。不要为维持11件强行保留失败接口。
- 轮轴承担转动载荷，评估实心轴+独立限位结构，分叉设计若保留须单独验证拆支撑和装入强度；不能预先宣称替代限位件一定可靠。
- 先确认受力相对层纹方向。卡扣若主要靠层间结合承受弯曲/剥离，应调整姿态或连接类型。不要仅靠提高填充比例解决只有几道线的细臂；看实际切片截面是否有连续承力线。
- 支撑避免接触卡扣有效柔性区/根部；优先无支撑接口朝向。对不可避免的支撑设计可清理空间。把拆支撑损伤也作为失败，而非认为模型完好后才开始测试。
- 不直接指定所有新模型统一壁厚、间隙或速度。记录同一打印机/喷嘴/材料/姿态的样件结果；参考参数应有验证状态和适用范围。

## 低成本闭环

先准备两到三种真实接口候选，分离测试间隙/倒扣与根部结构，不一次改变所有参数。先用同款耗材同向试打覆盖梁、挡边、锁定和拆卸空间；若用户还未回材料，可继续几何规划但不发布为已适配主盘。

小样验收需记录：去支撑无损、第一次装入、保持和转动、防脱、所需反复次数及裂纹/白化。目标循环次数和载荷由用途决定，不把手摆几下当疲劳寿命证明。失败时只迭代小样，通过后替换主盘接口、重做路径/活动与最终切片，减少整车重打。
